"The" olvidado

⚠️ Tu error #1: El artículo "THE" — lo olvidas constantemente

  • Antes de sustantivos concretos/específicos: the changes, the tests, the environment
  • Antes de equipos: the architecture team, the lake team
  • Antes de cosas únicas en contexto: the mapper, the pipeline, the next sprint
  • Truco: en español dirías "el/la/los/las" → en inglés casi siempre va the

🔴 Artículo "the" omitido (8 veces)

I have tested changes locally
I tested the changes locally
deploy it in development environment
deploy it to the development environment
run regression test
run the regression tests
how mapper is designed
how the mapper is designed
staging database hasn't been created by architecture team
the staging database hasn't been created by the architecture team
we should put issue in next sprint
we should carry the story over to the next sprint
💡 Regla: si en español pondrías "el/la/los/las", en inglés casi siempre necesitas the.

🔴 Falso amigo: "puntual"

It's a puntual error
It was a one-off issue / an isolated issue
💡 En inglés punctual = llegar a tiempo ⏰. Para algo que pasa una vez: one-off, isolated, sporadic.

🔴 Estructura incorrecta: "it's not need"

It's not need an additional action
It doesn't require any further action
No action is needed
💡 "Need" es verbo, necesita auxiliar: it doesn't need / it doesn't require. O usa la pasiva: no action is needed.

🔴 Confusión: "I'll see you with him"

I'll see you with him later
I'll talk to him later
I'll catch up with him after the daily
I'll sync with him after the daily
💡 "I'll see you" = "nos vemos" (al SM). Para decir "hablaré con él": I'll talk to him, I'll catch up with him, I'll check with him.

🔴 Vocabulario Scrum: "put" → "carry over / move"

We should put issue in next sprint
We should carry the story over to the next sprint
We should move the story to the next sprint
💡 En Scrum, cuando una historia pasa al siguiente sprint se dice carry over. También vale move, push, roll over.

⚠️ Past simple olvidado (2 veces)

I review the production logs (hablando de esta mañana)
I reviewed the production logs
I have tested changes locally (hablando de ayer)
I tested the changes locally
💡 En dailies, para cosas de ayer/esta mañana → past simple (reviewed, tested, fixed). El present perfect (have + past participle) se usa más cuando el resultado sigue siendo relevante ahora sin referencia temporal específica.

⚠️ Preposición: "deploy in" → "deploy to"

deploy it in development environment
deploy it to the development environment
💡 Se despliega to (destino) un entorno: deploy to staging, deploy to production. Pero: it's running in production (ubicación).

⚠️ Expresión: "during the day" → "by the end of the day"

I think I will finish it during the day
I think I'll finish it by the end of the day
I should be done by end of day
💡 "During the day" = a lo largo del día (proceso). "By the end of the day" = para cuando acabe el día (fecha límite). Abreviatura informal: by EOD.

🔴 Falso amigo: "identify" vs "identity"

start with identify microservice
start with the identity microservice
💡 identify = verbo (identificar). identity = sustantivo (identidad). El microservicio es de identidad → identity microservice.

🔴 Expresión: "in the meanwhile" → "in the meantime"

In the meanwhile, I will create a ticket
In the meantime, I'll create a ticket
Meanwhile, I'll create a ticket
💡 Las formas correctas son: in the meantime o meanwhile (solo). "In the meanwhile" no existe en inglés.

🔴 Vocabulario IT: "grants" → "permissions / access"

ask for the microservice grants
request the microservice permissions
request access to the microservice
💡 Grants = becas/subvenciones 💰. Para permisos IT: permissions, access, credentials (si son claves).

⚠️ Preposición: "ticket to architecture" → "ticket for the architecture team"

create a ticket to architecture
create a ticket for the architecture team
💡 El ticket es para un equipo → for. También: siempre añade team después del nombre del área (the architecture team, the infra team).

🔴 Sujeto "it" omitido

I'm quite sure is ready for the sprint review
I'm quite sure it'll be ready for the sprint review
💡 En inglés el sujeto es obligatorio. En español decimos "estoy seguro de que estará listo" (sin sujeto explícito). En inglés siempre: it will be, it is, it works.

⚠️ Expresión: "if the execution is fine" → expresiones más naturales

If the execution is fine
If everything goes well
If the tests pass
If there are no issues
💡 "The execution is fine" suena muy literal (traducción directa de "si la ejecución va bien"). Alternativas naturales: if everything goes well, if the tests pass, assuming no issues.

💎 Tips de naturalidad

  • Usa contracciones en conversación: I'll en vez de I will, it's en vez de it is
  • Matiza estados: una PR está open (abierta) vs ready for review (lista para revisar)
  • Verbos más naturales: look into (investigar), wrap up (terminar), pick up (coger tarea)
  • Para sonar senior: "I'd suggest...", "I expect to...", "We're done on our side"
